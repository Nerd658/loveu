# 💌 LoveU - The Ultimate Romantic Invitation

Une application Web interactive d'une seule page conçue pour une seule chose : **poser la question fatidique de manière inoubliable**. Fini les SMS banals, envoyez une expérience immersive, interactive et totalement "Wow".

## ✨ Fonctionnalités (L'Effet Wow)

- **L'Enveloppe Secrète 3D** : L'expérience commence par une enveloppe qui s'ouvre avec une animation 3D fluide pour révéler la question.
- **Bouton "Non" Fuyard** : Impossible de refuser ! Le bouton "Non" rétrécit, change de texte de manière humoristique et s'enfuit quand on essaie de cliquer dessus.
- **Parallax & Gyroscope** : L'application utilise les capteurs de mouvement du téléphone (ou la souris sur PC) pour incliner l'enveloppe et donner une vraie impression de profondeur 3D physique.
- **Curseur Magique** : Une traînée de poussière d'or magique suit le doigt ou la souris de l'utilisateur.
- **Golden Ticket VIP** : Une fois le "Oui" validé, une explosion de **confettis 3D** retentit et génère un "VIP Date Pass" doré, parfait pour une capture d'écran.
- **Design Sonore** : Des effets sonores subtils (Web Audio API) accompagnent chaque interaction (ouverture, clic furtif, victoire).

## 🛠️ Stack Technique

- **React 19** & **Vite**
- **Tailwind CSS** (Design "Glassmorphism" et UI Premium)
- **Framer Motion** (Animations 3D physiques, Spring physics, Parallax)
- **Canvas Confetti** (Particules de victoire)
- **Lucide React** (Icônes élégantes)

## 🚀 Comment lancer le projet en local

1. **Cloner le dépôt** et ouvrir le dossier.
2. **Installer les dépendances** :
   ```bash
   npm install
   ```
3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```
4. Ouvrez `http://localhost:5173` dans votre navigateur.

## 🌍 Déploiement

Ce projet est optimisé pour être déployé en 1 clic sur **Vercel** ou **Netlify**.
- **Build command** : `npm run build`
- **Output directory** : `dist`

Une fois déployé, envoyez simplement le lien à la personne concernée et attendez qu'elle vous renvoie la capture d'écran de son Ticket VIP ! 😉
